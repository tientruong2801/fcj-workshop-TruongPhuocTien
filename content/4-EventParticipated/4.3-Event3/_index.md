# Event Report: "Agentic AI Build Week - Hackathon" (25/07)

### Event Objectives
- Challenge myself by building a complete Minimum Viable Product (MVP) from scratch within a highly demanding 24-hour hackathon.
- Gain hands-on experience with modern Artificial Intelligence technologies, particularly Agentic AI integrated with the AWS cloud ecosystem.
- Experience an intensive team collaboration process, from idea generation and overcoming technical challenges to delivering a final project presentation before the judges.

### Participating Teams and Featured Projects
- **Team 3KA** (Huynh An Khuong, Nguyen Quoc Huy, ...): **S.H.E.P.H.E.R.D** – An AI-powered crowd monitoring and analytics system.
- **Team Plan V** (Pham Tien Thuan Phat, Huynh Hoang Long, ...): **SA Professional AI Native App** – An AI assistant for solution architecture design.
- **Dream AI Team** (Le Tan Luc, Do Hoang Hieu, ...): **Signal Scout** – A strategic business intelligence and analytics platform.

### Key Takeaways

#### S.H.E.P.H.E.R.D: AI-Powered Crowd Monitoring
- Addressed crowd management challenges by transforming ordinary surveillance cameras into intelligent systems capable of providing real-time operational insights.
- Combined Computer Vision technologies (YOLO and ByteTrack) with Amazon SageMaker and Amazon Bedrock Agents to estimate crowd density, predict congestion risks, and automatically notify event operators.
- Successfully completed the project within 24 hours despite having limited prior experience with AI and AWS.

#### SA Professional AI Native App: Automating Solution Architecture Design
- Targeted the challenge faced by Solution Architects when manually analyzing Business Requirement Documents (BRDs) and designing cloud architectures.
- Automatically analyzed natural language requirements, generated hybrid cloud architectures, produced Draw.io diagrams through the Model Context Protocol (MCP), and generated Infrastructure as Code (Terraform).
- Included an automated AWS cost estimation module covering services such as Amazon EC2, Amazon RDS, and Amazon S3.

#### Signal Scout: Strategic Business Intelligence
- Developed a decision-support platform that collects, validates, and connects scattered public information into meaningful strategic insights.
- Leveraged Amazon Bedrock and AgentCore Short-Term Memory to analyze financial indicators and support strategic decision-making.
- Presented a detailed cloud cost analysis by optimizing services such as AWS Lambda, Amazon DynamoDB, and AWS WAF, maintaining an estimated monthly operating cost between **USD 81 and USD 359**.

### Knowledge Gained

#### Design Thinking & Project Management
- **Deliver Finished Features:** A small, fully completed feature provides greater value than an ambitious but unfinished idea. Clearly defining project scope and completion criteria early is essential for successful project management.
- **Preparation Matters:** Working effectively under tight deadlines requires clear task allocation and well-prepared development environments before implementation begins.

#### Technical Architecture (AWS & AI)
- **Real-Time AI Inference Architecture:** Learned how Computer Vision models such as YOLO and ByteTrack can be integrated with Amazon SageMaker to analyze live video streams, estimate crowd density, and predict congestion while minimizing inference latency.
- **Multi-Agent AI Architecture:** Understood how multiple AI agents can work together, including an autonomous monitoring agent that continuously detects abnormal situations and an Amazon Bedrock Agent that enables natural language interaction with operational data.
- **Containerized Cloud Infrastructure:** Learned how to design secure cloud networks using Amazon VPC with public and private subnets. Backend services and AI agents were containerized and deployed on Amazon ECS Fargate, demonstrating the advantages of container-based deployment over traditional server management.
- **API Architecture and Cost Optimization:** Explored how AI applications communicate with AWS services through the Model Context Protocol (MCP), while combining AWS Lambda, Amazon DynamoDB, and Amazon API Gateway to build highly cost-efficient cloud applications.

### Applications to My Work and Studies
- Apply Agentic AI concepts inspired by the Plan V project to automate Infrastructure as Code (Terraform) generation for deploying Docker-based environments and distributed database systems.
- Adapt the real-time data processing techniques demonstrated by the S.H.E.P.H.E.R.D project to improve ETL pipelines, enabling faster data ingestion and automated latency monitoring.
- Apply the hackathon principle of **"scope it tiny"** by dividing large development tasks into smaller, independently deliverable features to improve productivity and maintain project progress.

### Event Experience

The most inspiring presentation for me was the journey of **Team 3KA** and their **S.H.E.P.H.E.R.D** project. Despite having limited experience with AI and AWS before the hackathon, the team demonstrated remarkable determination and teamwork throughout the 24-hour competition.

They successfully overcame numerous technical challenges, including maintaining stable real-time video streaming, tracking moving objects across video frames, and reducing inference latency. Their stories of staying awake until early morning, debugging continuously, forgetting to commit code, and relying on energy drinks to keep working perfectly illustrated the intensity of a real hackathon experience.

More importantly, the way S.H.E.P.H.E.R.D transformed an ordinary surveillance camera into an intelligent operational monitoring system using Computer Vision and Agentic AI demonstrated the practical impact of modern AI technologies. The project inspired me to explore how similar architectures could be applied to intelligent monitoring and automation systems in many other domains.
