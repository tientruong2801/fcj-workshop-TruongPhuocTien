This page summarizes the 8-week work progress (Worklog) for the **News RAG** project. My responsibilities focused on building the data ingestion pipeline (Crawler), text cleaning and processing (ETL), User Interface development (Frontend), and personally deploying the ingestion flow onto the cloud infrastructure.

The project timeline was divided into clear phases: from architectural surveying and achieving 100% completion in the Local environment, to Containerization and Serverless deployment on the AWS Cloud, and finally, collaborative end-to-end testing and report writing.

Details of the weekly tasks are as follows:

**Week 1:** [Surveying AWS architecture, Serverless services, and setting up the Local Docker environment](1.1-week1/)

**Week 2:** [Finalizing architecture, distributing tasks, and designing the Data Warehouse](1.2-week2/)

**Week 3:** [Developing the Crawler module with Scrapy and pushing data streams to Kafka](1.3-week3/)

**Week 4:** [Programming the ETL module, text cleaning, and Semantic Chunking algorithm](1.4-week4/)

**Week 5:** [Developing the Web App (Next.js), monitoring Dashboard, and AI Chat Interface](1.5-week5/)

**Week 6:** [Dockerizing the Crawler and deploying to AWS Fargate and EventBridge](1.6-week6/)

**Week 7:** [Understanding team Cloud infrastructure and connecting the Frontend to AWS APIs](1.7-week7/)

**Week 8:** [Conducting End-to-End testing, finalizing the project report, and defense slides](1.8-week8/)
